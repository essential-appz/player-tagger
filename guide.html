Getting Started

Starting a New Game

  1. Open Settings: Click the Settings button (top-left)
  2. Configure Game Type: Select your sport from the dropdown
    • Gaelic Games (GAA): 15 starting players + 11 substitutes in traditional formation
    • Soccer: 11 starting players + 11 substitutes in 4-4-2 formation
  3. Enter Team Names: Type team names (auto-generates game title with date)
  4. Configure Descriptors (Premium): If you have premium, customize your event descriptors
    • Add, delete, or reset descriptors as needed
    • Changes will be applied when you click New Game
  5. Click New Game: Player layout updates, descriptors apply, and modal closes

Recording Your First Event

  1. Start the Game: Click "Start 1st Half" to begin the game timer
  2. Select a Player: Click a player button (e.g., "OUR 5" or "OPP 12")
    • "Touch" is automatically added to every event
    • Player buttons are arranged in sport-specific formations
  3. Add Event Descriptors: Click additional event types
    • Shot, Goal, Point, 2 Pointer, T/O Won, etc.
    • Click again to deselect
  4. Save the Event: Click "Manual Save Event" or select another player to auto-save
  5. Review Recent Events: Check the Recent Events panel to verify or delete mistakes

Common Workflows

Managing Game Periods

  • Start 1st Half: Begins game clock at 00:00
  • End 1st Half: Stops clock, captures half-time scores automatically
  • Start 2nd Half: Resumes game clock at 30:00
  • End 2nd Half: Completes the game timing
  • End Game: Saves final data, optionally starts new game

Viewing Match Timeline

  1. Click the Timeline button in main controls
  2. View chronological scoring events with:
    • Game time for each score
    • Player number and event type
    • Running score after each event
    • Half-Time and Full-Time summary rows
  3. Click X to close the modal

Ending a Game

  1. Click End Game button in main controls
  2. Confirm: "End game and save final data?"
    • Saves current game as "full game"
    • Clears all "in-progress game" checkpoints
  3. Choose next action:
    • Yes: Clears data and opens Settings to configure new game
    • No: Keeps game data visible for review and CSV export
  4. Download CSV to export final data if needed

Recent Events Panel

The Recent Events panel shows your last 10 events with individual delete buttons:

  • Quick visual reference of recent activity
  • Delete any recent event (not just the last one)
  • Shows game time, player, and descriptors for each event
  • Updates in real-time as you log events

Event Matrix

Interactive tables showing event counts by player and descriptor:

  • Separate matrices for OUR team and OPP team
  • Click column headers to sort by any event type
  • Ascending/descending toggle
  • Highlighted cells for players with events
  • Sticky headers for easy scrolling

Analytics & Reports

Live Statistics (Free)

  • Scoreboard: Real-time score tracking with goals and points
  • Game Clock: Running timer showing current game time
  • Half-Time Scores: Displayed below current scores after 1st half ends
  • Event Counts: Updated matrices showing all event totals

Game Reports⭐ PREMIUM

Click the Reports button to access comprehensive analytics:

Possession Statistics

Time-based possession with half-by-half breakdown. Shows 1st Half, 2nd Half, and Total possession time (MM:SS format) with percentage.

Shot Conversion

Shooting efficiency metrics broken down by period. Shots, Scores, and Conversion % for each half and total game.

Kickout Analysis

Kickout win/loss statistics per half. Own kickout and opposition kickout success rates with totals.

Top 3 Possessions

Most active players ranked by touches. Identifies key ball carriers.

Top 3 Scorers

Leading scorers with Goals, 2-Pointers, Points columns. Total Points value calculated and sorted.

💡 Using Half-by-Half Analytics

  • Compare 1st half vs 2nd half possession to identify conditioning trends
  • Check shot conversion drops between halves to assess finishing under fatigue
  • Review kickout success rates to evaluate tactical adjustments
  • Use reports at halftime for real-time coaching decisions

Premium Features

Custom Event Descriptors⭐ PREMIUM

  1. Activate premium license or start free trial
  2. Click Settings button
  3. Scroll to Custom Event Descriptors section
  4. Type a descriptor name and click Add (or press Enter)
  5. Click × next to any descriptor to delete it
  6. Click Reset to Defaults to restore original 7 descriptors
  7. Click New Game to apply your descriptor changes

⚠️ Important

Descriptor changes are only applied when starting a new game. This ensures data integrity and prevents conflicts with in-progress games.

Save & Load System⭐ PREMIUM

Saving Progress:

  • Click Save Game Progress anytime to create checkpoint
  • Multiple checkpoints can be saved per game
  • Each save shows timestamp, event count, and sport type
  • Labeled as "in-progress game" until you end the game

Loading Games:

  1. Click Settings button
  2. Scroll to Saved Games section
  3. Browse list with sport type and save type labels
  4. Click Load to restore that game state
  5. Click Download to export as CSV
  6. Click Delete to remove individual saves

Video Sync & Clip Generation⭐ PREMIUM

  1. Sync Video Timestamps:
    • Click Video button in main controls
    • Enter when 1st Half starts in your video (e.g., 02:30)
    • Enter when 2nd Half starts (e.g., 47:15)
    • Click Save Video Sync
  2. Configure Clip Filters:
    • Select team from dropdown
    • Choose clip type (Scores, Kickouts Won, Kickouts Lost)
    • Adjust seconds before/after event
  3. Generate Commands:
    • Click Generate Clip Commands
    • Review FFmpeg commands in output panel
    • Click Copy to Clipboard
  4. Execute in Terminal:
    • Open terminal in directory with game.mp4
    • Paste and run commands
    • Clips extracted with format: clip_1_OUR5_0312_Goal.mp4

CSV Import⭐ PREMIUM

  1. Receive CSV file from another Player Tagger user
  2. Click Import CSV button in the app
  3. Select the CSV file
  4. Game data loads automatically with:
    • All events and timestamps
    • Custom descriptors (auto-detected and created)
    • Period state restoration
    • Team names and scoreboard

Data Management

Data Storage

All data is stored locally in your browser using localStorage:

  • Current game events
  • Team names and game settings
  • Saved game checkpoints (Premium)
  • Custom event descriptors (Premium)
  • Video sync timestamps (Premium)
  • License key and trial status

⚠️ Important

Clearing browser data will delete all saved games and settings. Always export important games as CSV for permanent backup.

CSV Export (Free)

Export complete event log with all details:

  • Event number
  • Timestamp (ISO format)
  • Game time (MM:SS)
  • Period (1st Half Started, 2nd Half Ended, etc.)
  • Team type (OUR/OPP)
  • Player category (e.g., OUR 5)
  • Event descriptors (comma-separated)

Browser Compatibility

Works best on modern browsers:

  • Chrome/Edge (desktop & mobile)
  • Safari (desktop & mobile)
  • Firefox (desktop & mobile)

Tips & Best Practices

For Free Users

💡 Getting the Most Out of Free Features

  • Select the correct Game Type before starting (cannot be changed mid-game)
  • Use End Game button for streamlined game completion workflow
  • Download CSV after each game for permanent backup
  • Use event matrix sorting to track most active players
  • Review Recent Events panel frequently to catch mistakes early
  • Click Timeline to see scoring progression throughout the game
  • Start your 14-day free trial to explore all premium features

For Premium Users

⭐ Maximizing Premium Features

  • Use Save Game Progress frequently during games for backup checkpoints
  • Click Reports at halftime to view analytics and adjust strategy
  • Check possession stats during breaks to evaluate ball control
  • Use half-by-half breakdown to identify performance trends
  • Compare 1st vs 2nd half shot conversion to assess finishing under fatigue
  • Configure custom descriptors in Settings before starting new game
  • Share games with coaches/teammates by downloading CSV for import
  • Download saved game checkpoints as external backups
  • Import previous games to analyze patterns across multiple matches
  • Video Sync: Note video start times immediately after recording
  • Start with 10 sec before, 20 sec after for clip context
  • Generate clips for individual players or entire team highlights
