## Quick Response Notes

### When user emails for trial:
1. Open `generate-license-keys.html`
2. Click "Generate Trial Key"
3. Copy the key
4. Use "Trial Request Response" template
5. Replace TRIAL-XXXX-XXXX-7D with generated key
6. Send!

### When user purchases:
1. Confirm payment received (€79)
2. Open `generate-license-keys.html`
3. Click "Generate PRO Key"
4. Copy the key
5. Use "Purchase Confirmation Response" template
6. Replace PRO-XXXX-XXXX-XXXX with generated key
7. Send!

### Tracking (Optional)
Keep a simple spreadsheet:
- Email address
- Key issued
- Type (TRIAL/PRO)
- Date sent
- Expiry date (for trials)
- Payment status (for PRO)
